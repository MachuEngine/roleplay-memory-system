# 롤플레이 memory 데모

캐릭터를 설정하고 대화하면서 세 가지를 확인할 수 있습니다.

- **말투 유지**: 입력한 말투와 대화 예시를 대화 내내 지킵니다.
- **기억 반영**: 대화 6회마다 확정된 사실(L1 profile)과 상태를 바꾼 사건(L2 episodes)을 정리해 다음 응답에 넣습니다.
- **사용자 행동 대리 금지**: 캐릭터가 사용자의 말이나 행동을 대신 쓰지 않도록 지시하고, 응답마다 규칙 기반 검사로 의심 문장을 표시합니다. 규칙 기반 판정은 "하람이 던진 질문에"처럼 사용자를 꾸미는 표현도 잡는 오탐이 있어 차단하지 않습니다. 형식이 깨진 응답(행동 문단으로 시작하지 않음, 분석 노출, 사용자 이름표 대사 등)은 1회 다시 생성하고, 다시 실패하면 캐릭터만 행동하는 짧은 응답으로 대신합니다.

## 구성

- 메인 모델: Gemini 2.5 Pro (OpenRouter 경유, thinking 128토큰, 출력 1,200토큰)
- 기억 정리: Gemini 2.5 Flash-Lite
- 대화 내역은 최근 6,000토큰(추정) 안에서 보내고, 기억으로 정리되기 전의 대화는 예산을 넘어도 원문으로 유지합니다.

## 사용량 제한

- 세션당 20턴, 데모 전체 하루 200턴
- 일일 카운터는 서버 메모리에 있어 Space가 재시작되면 초기화됩니다. 비용 상한은 API 키에 건 크레딧 한도로 따로 막아 둡니다.
- 대화 내용은 서버에 저장하지 않습니다.
